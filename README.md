# Автоматизация тестирования сервиса Яндекс.Самокат

Проект представляет собой автоматизированные тесты для веб-сервиса Яндекс.Самокат (https://qa-scooter.praktikum-services.ru/), созданные с использованием Python и Selenium. Тесты проверяют функциональность оформления заказа, навигацию по логотипам и раздел FAQ.

## Требования
- Python 3.13+
- Selenium
- pytest
- allure-pytest
- Allure Commandline (для генерации отчётов)
